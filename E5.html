Épreuve E5 — Cybersécurité et services

Cette page regroupe mes situations professionnelles significatives réalisées dans le cadre du BTS SIO option SISR.

Situation 1 — Infrastructure réseau virtualisée

Contexte : Dans le cadre d'un TP noté en BTS SIO, j'ai conçu et déployé une infrastructure réseau fonctionnelle entièrement virtualisée sous VMware, reproduisant les conditions d'un environnement professionnel.

Tâches réalisées :

  • Installation et configuration d'un serveur Windows Server avec le rôle Active Directory.
  • Déploiement et paramétrage des services DNS et DHCP.
  • Configuration des machines virtuelles clientes jointes au domaine.
  • Tests de validation de l'infrastructure (authentification, DHCP, DNS).

Compétences mobilisées :

  • Virtualisation d'infrastructure (VMware)
  • Administration Windows Server
  • Configuration Active Directory, DNS, DHCP
  • Diagnostic et résolution de problèmes réseau

Difficultés rencontrées : La principale difficulté a été de centraliser et relier l'ensemble des services sur une seule machine serveur sans conflit de configuration.
