Serveur de fichiers sous Linux (Samba)

Linux Samba Active Directory Partage réseau Droits d'accès

Contexte

Dans le prolongement du projet Active Directory, j'ai déployé un serveur de fichiers Linux intégré au domaine AD, permettant le partage de ressources entre les postes clients Windows et le serveur Linux via le protocole SMB.

Missions réalisées

  • Installation et configuration de Samba sur une machine virtuelle Linux (Debian).
  • Intégration du serveur Linux au domaine Active Directory existant.
  • Création de partages réseau avec gestion fine des droits d'accès par groupe AD.
  • Montage automatique des partages sur les postes clients Windows via GPO.
  • Tests de validation : accès aux partages selon les profils utilisateurs.

Difficultés rencontrées

L'intégration du serveur Linux au domaine Active Directory a nécessité une configuration précise de Kerberos et des fichiers smb.conf. La synchronisation des permissions entre les droits Linux (chmod/chown) et les ACL Windows a demandé plusieurs ajustements.

Compétences mobilisées

  • Administration Linux (Debian) en ligne de commande
  • Configuration de Samba et du protocole SMB
  • Intégration Linux/Windows dans un domaine Active Directory
  • Gestion des droits d'accès et des GPO

Conclusion

Ce projet m'a permis de consolider mes compétences Linux et de comprendre l'interopérabilité entre environnements Windows et Linux, une compétence clé pour un administrateur réseau en entreprise hétérogène.
